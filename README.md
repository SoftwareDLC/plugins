# SoftwareDLC plugins

SoftwareDLC's Claude Code plugins.

| Plugin | Version | What it does |
| --- | --- | --- |
| [softwaredlc](plugins/softwaredlc) | 0.10.3 | (Beta) Build a first SoftwareDLC graph from your code, and inspect and author SoftwareDLC graph proposals in an explicitly bound local AI worktree. |

Install from this marketplace:

```text
/plugin marketplace add SoftwareDLC/plugins
/plugin install <plugin>@softwaredlc
```

This repository is published from the SoftwareDLC repository, where the plugins are built and
tested, at each production release. Changes made here are replaced at the next publish.
